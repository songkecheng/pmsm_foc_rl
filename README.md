# PMSM FOC 与强化学习仿真项目

本项目用于永磁同步电机（PMSM）的仿真、磁场定向控制（FOC）和强化学习研究。

## 激活 Python 环境

```bash
cd /home/user/pmsm_foc_rl
source .venv/bin/activate
```

## 安装项目依赖

```bash
python -m pip install -r requirements.txt
```

依赖文件包含 PyTorch CUDA 13.0 版本。安装和使用该版本需要可用的 NVIDIA 显卡驱动。电机仿真主要由 CPU 执行，PyTorch 可使用 CUDA 训练神经网络。

## 快速检查 PMSM 仿真环境

```bash
python check_environment.py
```

该脚本会创建连续电流控制 PMSM 环境，重置环境并执行一个动作，检查环境接口能否与 Stable-Baselines3 配合使用。

## 当前仿真目标电机

当前选定的电机是 **42JSF840AS-1000-8**。下表根据本项目收到的电机规格图整理，可作为 Gym Electric Motor（GEM）的初始配置。标注为“暂定”的数值或定义，需确认后才能用于精确的定量结论。

| 项目 | 规格或 GEM 参数 | 说明 |
|---|---:|---|
| 电机类型 | 三相 PMSM | 永磁同步电机 |
| 直流母线电压 | 24 V | GEM 的电源电压 `u_nominal` 设为 24 V；默认 PMSM 环境使用 300 V，需覆盖默认值。 |
| 磁极数 / 极对数 | 8 / 4 | GEM 电机参数 `p=4`。 |
| 额定转速 | 4000 rpm（约 418.9 rad/s） | 这是额定转速；规格图没有说明它是最高转速。 |
| 额定电流 | 4.5 A | 需确认是有效值还是峰值。若指相电流有效值，正弦电流峰值约为 6.36 A。 |
| 峰值电流 | 13.5 A | 需确认电流定义，并确认与实际驱动器的限流能力匹配。 |
| 额定转矩 / 峰值转矩 | 0.19 / 0.35 N·m |  |
| 额定输出功率 | 78 W |  |
| 定子电阻 `r_s` | 0.59 Ω（暂定） | 规格图没有说明这是相电阻还是线间电阻；正式使用前需确认。 |
| d/q 轴电感 `l_d`、`l_q` | 各 0.66 mH（暂定） | 规格图只给出一个电感值，没有分别提供 d 轴和 q 轴值。初步假设 `l_d ≈ l_q = 0.00066 H`。 |
| 反电势常数 | 2.95 Vrms/kRPM，线间值 | 规格图标为 `Ke(RMS-L)`。按正弦 PMSM 的线间有效值定义换算，GEM 磁链参数 `psi_p` 暂估为约 0.00575 Wb。 |
| 转子转动惯量 `j_rotor` | `1.85e-5 kg·m²` | 规格图已提供。 |
| 仿真控制步长 `tau` | 初始设为 `1e-4 s` | 这是 GEM 默认值；确定实际控制板的电流环周期后再调整。 |
| 初始负载转速 | 电流环初测设为 0 rad/s | 电流响应稳定后，再增加不同固定转速的测试工况。 |

规格图的传感器接线表列出了 Hall U/V/W，但没有列出编码器 A/B/Z 接线。GEM 的理想电机模型不需要真实编码器接线；进行实物 FOC 测试前，仍需确认电机是否带编码器，以及编码器信号如何引出。

`Cont-CC-PMSM-v0` 环境的动作是归一化电压指令。它本身不会自动实现本项目所需的固定 PI 电流控制器或“强化学习辅助 PI 参数调整”；这些控制器和对比实验流程还需要另外实现。

## VS Code 配置

在 VS Code 中打开本项目目录，并将 Python 解释器设置为 `.venv/bin/python`。

- `results/`：生成的图表和数据

- `check_environment.py`：仿真环境安装检查脚本
