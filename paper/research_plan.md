# 初步研究问题与测试工况

> 状态：工作假设，先用于指导基线实现和仿真；结果出来后再决定是否收窄或调整论文主张。

## 拟定题目

**Reinforcement-Learning-Assisted PI Gain Adaptation for Robust PMSM Field-Oriented Current Control under Parameter Variation**

中文：参数变化下强化学习辅助的永磁同步电机磁场定向电流控制 PI 增益自适应。

## 研究问题

在 PMSM 的 FOC 电流环中，强化学习辅助的 PI 增益调整能否在电机参数偏差下，相比固定 PI 增益降低电流跟踪误差，同时保持闭环稳定并满足电流、电压约束？

研究范围限定为仿真中的电流环。RL 只调整 PI 增益，不直接取代 FOC 电流控制器；固定 PI 是主要基线。论文是否能声称“提升”，必须由同等工况、多随机种子结果支持。

## 方法比较

1. **固定 PI 基线**：使用同一组额定参数下整定的 d/q 轴 PI 增益，所有测试工况保持不变。
2. **RL 辅助 PI**：保留 PI 电流控制结构，智能体根据电流误差等观测量，对 d/q 轴 PI 增益作有界的小幅调整；每步动作限幅，电压指令继续受逆变器和电流限制保护。

主要比较对象是固定 PI。所有控制器使用相同 PMSM 模型、参考信号、采样周期、逆变器限制和随机种子。先跑通固定 PI，再接入 RL。

## 测试工况矩阵

| 编号 | 工况 | 目的 |
|---|---|---|
| C0 | 额定 PMSM 参数；`i_d* = 0`，`i_q*` 做阶跃与正负方向变化 | 验证模型、FOC 和 PI 基线；记录标称性能 |
| C1 | 定子电阻 `R_s` 相对标称值增加 50% | 测试温升导致电阻偏差时的鲁棒性 |
| C2 | `L_d` 与 `L_q` 同时相对标称值偏差 +20% | 测试电感参数误差 |
| C3 | `R_s` +50%，`L_d/L_q` +20% | 测试组合参数偏差；若前面不稳定，先不跑此项 |

参数偏差作为模型与控制器之间的失配：控制器整定仍使用标称参数，测试时只改变被控电机参数。每项工况在固定 PI 和 RL 辅助 PI 下使用相同参考轨迹和种子。

## 指标

- d/q 轴电流 RMSE（主指标）
- 超调量、上升时间、调节时间
- 电流误差积分（IAE）
- 电流/电压限幅触发情况；失稳或发散次数

至少报告多次独立随机种子的均值与标准差；若在 10 月 8 日前无法稳定完成训练，则保留可靠的固定 PI 结果，并如实缩小论文范围，不把未验证的 RL 效果写成结论。

## 当前环境核对与实现关口

已检查当前 Gym Electric Motor 环境 `Cont-CC-PMSM-v0`：展平后的观测维度为 16，动作维度为 3。它提供连续 PMSM 电流控制仿真，但还没有本项目的 FOC、固定 PI 或 RL 增益调整实现。因此，下一步先确认电机状态、参考量、转子角和动作定义，明确 FOC 与逆变器接口，再实现并验证固定 PI。只有固定 PI 的电流跟踪和限幅行为正确后，才开始训练 RL。

本计划中的参数比例与参考波形是首轮实验设计，不是已经验证的性能结论；如果仿真额定值或模型支持范围不匹配，要在基线阶段调整并记录。
