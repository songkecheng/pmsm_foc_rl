# IEEE conference paper template

`main.tex`, `IEEEtran.cls`, and `IEEEtran.bst` are copied from the IEEEtran conference proceedings template package downloaded from CTAN. The untouched package archive and extracted source are in `../ieeetran-template.zip` and `../template-source/IEEEtran/`.

The ONCON 2026 call currently specifies IEEE double-column formatting and a six-page full-paper limit, but its submission page does not yet provide a conference-specific template. Recheck the conference submission page before final formatting in case ONCON publishes additional instructions.

The machine does not currently have `pdflatex` installed, so this template has not been compiled locally yet.
